# TC-A1-02: 缺 Constraint 时 G-A1 判 fail

- **规则**：G-A1
- **检验目的**：反向对照——验证“至少一个 Constraint”子句在缺失时确实判 `fail`
- **输入**：谓词快照，含 Project、Actor、Outcome、Commitment，但 Constraint 集为空
- **预期结论**：`fail`
- **预期原因**：`missing_constraint`

## 输入快照

```yaml
project: { id: "P-TC-A1-02" }
actors: [{ id: "A-1", type: "HumanActor" }]
outcomes: [{ id: "O-1" }]
commitments: [{ id: "C-1", by: "A-1", to: "O-1" }]
constraints: []
```

## 判定过程（预期）

1. `PROJECT_MINIMAL_EXISTENCE` 检查四类节点：Project ✓、Actor ✓、Outcome ✓、Commitment ✓、Constraint ✗。
2. 因 Constraint 集为空，`至少一个 Constraint` 子句不满足。
3. 输出 `fail`，原因为 `missing_constraint`。

## 备注

无。
