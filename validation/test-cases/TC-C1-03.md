# TC-C1-03: 多 Deliverable 中部分有 Assertion 时 G-C1 判 fail

- **规则**：G-C1
- **检验目的**：量词边界——验证“每个 Deliverable”是全称量词，部分满足不等于整体满足
- **输入**：谓词快照，含 D-1（有 Assertion）、D-2（无 Assertion）
- **预期结论**：`fail`
- **预期原因**：`deliverable_without_assertion`，指名 D-2

## 输入快照

```yaml
deliverables:
  - { id: "D-1", asserted_by: ["As-1"] }
  - { id: "D-2" }
assertions:
  - { id: "As-1", about: "D-1" }
```

## 判定过程（预期）

1. 遍历每个 Deliverable。
2. D-1：`asserted_by` 非空 → 通过。
3. D-2：`asserted_by` 缺失 → 该 Deliverable 不满足。
4. 全称量词失败 → 输出 `fail`，原因为 `deliverable_without_assertion`，指名 D-2。

## 备注

若误用存在量词（“至少一个 Deliverable 有 Assertion”），会误判为 `pass`。本用例专门检验这一量词边界。
