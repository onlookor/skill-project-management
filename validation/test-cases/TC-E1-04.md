# TC-E1-04: Accountable 与 Responsible 重合但缺声明

- **规则**：G-E1
- **检验目的**：例外触发——验证角色合并声明的处置
- **输入**：谓词快照，C-1 的 Accountable 与 Responsible 均为 A-1（HumanActor），未声明 `role_merge_declaration`
- **预期结论**：`warn`（不是 `pass`，也不是 `fail`）
- **预期原因**：`role_merge_without_declaration`

## 输入快照

```yaml
commitments:
  - id: "C-1"
    accountable_by: "A-1"
    responsible_by: ["A-1"]
    role_merge_declaration: null
actors:
  - { id: "A-1", type: "HumanActor" }
```

## 判定过程（预期）

1. Accountable 唯一 ✓，指向 HumanActor ✓。
2. Responsible 至少一个 ✓。
3. 二者重合，且 `role_merge_declaration` 为 null → 触发 warn。
4. 输出 `warn`，原因为 `role_merge_without_declaration`。

## 备注

**本用例暴露 ERRATA E-004 的规格缺口**：原判定摘要将“重合且缺声明”归为 `block`，但走查样例表明更合理的处置是 `warn`（角色合并本身合法，只是需要声明）。修正登记于 `TODO.md` T-100。
